# RayBox-rx：XHTTP RX 现场结果摘要

日期：2026-10-30。本文件为脱敏摘要。测试机地址、域名、SSH信息、认证配置和原始现场日志不随源码发布。历史技术名为 Xray-RX。

## 已确认与未完成

- 指定俄罗斯测点经一个可用 Cloudflare 入口到英国源站，普通 XHTTP 未启用 RX，单次完整 1GiB 已通过：1,073,741,824 字节、SHA-256一致，28.095秒、36.447MiB/s，正常TLS证书验证。不能将该结果归功于RX或外推全部入口、运营商和时段。
- 同一路径的受限入口上，旧RX 1GiB样本600.007秒仅4096字节，失败。重开成功不等于应用文件交付。
- 固定100字节填充、1KiB串行分段：单次64KiB前缀20.976744秒完整、hash一致；只增大为2KiB后120.033291秒仅5934字节，已收前缀与源站同长度一致，目标失败。填充同时影响请求与响应，跨时段样本不能证明确定的字节或包数阈值。
- 首轮N4并发：27.007250秒0字节，在首次RX确认前失败，没有进入并发。4次TLS全握手耗时4769至4831ms，几乎用完5000ms拨号/TLS/响应头总期限。服务端只有启动日志；不能据此证明请求在诊断点前完全未到达。
- 将请求期限调整为10000ms后的N4单次64KiB：41.286400秒完整，SHA-256一致。N16单次64KiB：48.395226秒完整，SHA-256一致。两轮原始前缀、结果和服务清理已独立核对；含启动的平均速度分别约1.55KiB/s和1.32KiB/s，不能以短数据阶段速度替代整请求吞吐。

后续源码包含启动握手竞速、响应截止及多地址实验能力；它们的存在不表示持续速度、1GiB或容量验收通过。本次源码发布没有重跑现场下载。

## 完成口径

完整1GiB与实际可用持续吞吐必须在同一指定受限路径上另行验收。64KiB小样本、本地故障注入、换段确认或某次数据阶段突发速度均不足以认定业务目标完成。

记录应包括应用字节数与SHA-256、完整耗时和吞吐、启动等待、真实恢复、底层连接、额外流量、CPU/RSS、缓存和并发峰值。HTTP请求数不等于TCP数，socket字节不等于CDN账单。加密包长不能直接确定TLS消息或网络限流机制。

## 安全与隔离

实验使用独立目录、端口、unit和截止时间。上述N4/N16轮次结束时实验节点、源站、客户端与抓包均已停止，生产进程保持不变；这是当轮结束快照，不代表实时远端状态。源码发布不修改生产服务，也不发布可直接连接测试机的配置。
