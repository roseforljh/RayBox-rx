# 受限入口MSS与RX分段现场结果（2026-10-30授权窗口）

## 条件

指定俄罗斯测点经CF到英国自有源站。只使用分类首轮13个"TCP建立但0应用字节"的候选IP，未扫描新IP。普通TLS验证保持，独立临时unit，生产监听及PID每轮前后回读未变。原始抓包、日志在被忽略的 `artifacts/mss-field-20261030/`、`split-field-20261030/`、`rxmss*-field-20261030/`、`rxbatch-field-20261030/`。

## 受限入口的两层限制（抓包证据）

1. **满长包黑洞**：三轮旧抓包中这些IP从未到达IP总长1500的下行包，CF拆小后的重传（1024+424、1428）能到。客户端 `TCP_MAXSEG` 1360后13个IP握手全部完整；1440（IP总长1480）在后续轮次中有数千个到达。分类工具新增 `tcp_max_seg`，Xray用 `sockopt.tcpMaxSeg`，RX拨号经 `internet.DialSystem` 生效。
2. **单连接下行包数限额**：MSS修好后每条连接约在第9~10个下行包后双向冻结（SYN-ACK、纯ACK、FIN都计入，上行不计）。不按时间算。ClientHello拆成64字节TCP段或64字节TLS记录均无改善。RX恢复握手下单段正文实际上限约4KB；5KB段多数、6KB及8KB段几乎全部撞线。
3. **整体带宽天花板**：RX 4KB×64并发时下行L3稳定在约0.9~1.1MB/s（约1650包/秒）。只用6个、7个、13个IP平顶相同，说明按客户端整体限速，不随IP数增加。128并发超出后拥塞崩溃。

新建连接速率未见限制（0.25秒63个SYN全部应答）。

## NEL对照

用户授权后关闭zone NEL（2026-10-30T20:53:55Z），随后又恢复为开启（21:02:32Z，即原状态）。关闭后4KB段每连接读取由约5800降至约5450字节，但"票据+响应头"仍跨两个包，没有省下包数。紧邻A/B（4KB×64、MSS1440、8MiB）：NEL关0.356MB/s、重试474；NEL开0.476MB/s、重试107。另一轮NEL关闭恰逢整体天花板降至约0.55MB/s，仅0.171MB/s，时段波动不能排除。未观察到关闭NEL的收益，因此保留开启。
